Template Code Editor for Anki

This add-on upgrades the text area in Cards… with a Monaco-powered editor for front templates, back templates, and card styling.

Features

  • Syntax highlighting for HTML, embedded CSS and JavaScript, and standalone card CSS
  • HTML, CSS, and JavaScript autocompletion
  • CSS color previews and a color picker
  • Prettier document and selection formatting for HTML, embedded JavaScript, and CSS
  • Syntax diagnostics for standalone CSS and JavaScript inside <script> tags
  • Line numbers, code folding, automatic indentation, paired brackets and quotes, and automatic HTML closing tags
  • Light and dark themes that follow Anki's theme
  • Per-tab scroll position, cursor, and selection memory while the Cards window is open
  • Persistent indentation and tab settings
  • Full support for Anki's live preview, search, Add Field, Save, and Cancel behavior
  • No network connection required at runtime

Using autocompletion

Use the arrow keys to select a suggestion, then press Tab or Enter to accept it. Press Ctrl+Space to open suggestions at any time.

Compatibility

Anki 2.1.50 and newer, including current 25.x and 26.x releases.
